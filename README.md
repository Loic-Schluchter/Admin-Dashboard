# Admin Dashboard

Un tableau de bord administrateur réalisé dans le cadre du parcours Intermediate HTML and CSS de The Odin Project.

## Voir le projet en ligne
[Admin-Dashboard](https://loic-schluchter.github.io/Admin-Dashboard/)
## Objectif

Reproduire une interface de tableau de bord administrateur en utilisant principalement CSS Grid pour organiser les différentes sections de la page.
L'objectif était de reproduire selon une capture d'écran un dashboard administrateur.

## Technologies utilisées
- HTML5
- CSS3
- CSS Grid
- Flexbox

## Compétences développées
CSS Grid : création de mises en page complexes et organisation des différents éléments.
Grid & Flexbox : combinaison des deux systèmes de mise en page.
CSS Functions : utilisation de min(), max() et minmax() pour gérer les dimensions.
## Bilan personnel
Ce projet m'a permis de mieux comprendre la puissance de CSS Grid pour construire des interfaces complexes.
J'ai notamment appris à imbriquer plusieurs grilles, à mieux contrôler les dimensions des colonnes et des lignes et à combiner Grid et Flexbox pour obtenir une mise en page plus précise.
